## 1. Целые числа

### Как хранится положительное число

Число переводится в двоичный код и записывается в ячейку памяти фиксированной ширины (в битах).

От количества бит зависят базовые целочисленные типы: `byte`, `short`, `int`, `long`.

### Дополнительный код: как получить `-x` из `x`

Формула:

```text
-x = ~x + 1
```

1. Операция `~` (NOT) инвертирует все биты: `0 → 1`, `1 → 0`.
2. К результату прибавляется `1`.

Старший бит — знаковый: `0` = плюс, `1` = минус.

**Зачем так:** при знаковых числах половина диапазона уходит на отрицательные. Числовая «прямая» на железе — не бесконечная линия, а **кольцо** (как барабан секундомера): после максимума идёт минимум. Поэтому арифметика сложения/вычитания работает одной схемой и для плюса, и для минуса.

### Почему `-int.MinValue == int.MinValue`

У `int.MinValue` нет положительной пары в диапазоне типа: «следующее» после максимума по кольцу снова попадает в минимум. Места под `+2147483648` в 32 битах нет.

### Что такое `checked` в C#

`checked` заставляет арифметику при переполнении **кидать исключение**, а не молча заворачивать результат.

Для денег используют `decimal`, не `checked`.

## 2. Числа с плавающей точкой (IEEE 754)

### Из чего состоит `float` (32 бита)

| Поле | Биты | Смысл |
|------|------|--------|
| Знак | 1 | `0` — плюс, `1` — минус |
| Порядок (exponent) | 8 | степень / масштаб |
| Мантисса | 23 | значащие цифры |

Пример смысла: у числа вроде `0.0314` мантисса хранит значащую часть (`3.14…`), порядок — куда сдвинуть запятую (масштаб около `10⁻²`).

### Смещение порядка (bias)

Чтобы хранить и отрицательные, и положительные порядки без отдельного знака, к настоящему порядку прибавляют **bias = 127**.

```text
хранится = настоящий_порядок + 127
```

Пример: настоящий порядок `-5` → в памяти `122` (`-5 + 127`).

У `1.0f` в памяти порядок = `127` (настоящий порядок `0`).

### Почему `0.1 + 0.2 != 0.3`

`float`/`double` хранят дроби в двоичном виде с погрешностью.  
`0.1 + 0.2` даёт что-то вроде `0.30000000000000004`, а не ровно `0.3`.

Сравнивать так:

```csharp
Math.Abs(a - b) < 0.00001; // или другой допуск под задачу
```

### `decimal` — когда нужен

Нужен, когда важна **точность**, а не скорость (деньги, финансы). Медленнее `double`, зато считает в десятичной модели и не даёт классическую ошибку `0.1 + 0.2`.

## 3. Типы C# и Java

| C# | Java | Размер | Value / reference |
|----|------|--------|-------------------|
| `int` | `int` | 4 байта (32 бита) | value / примитив |
| `long` | `long` | 8 байт (64 бита) | value / примитив |
| `byte` | `byte` | 1 байт (8 бит) | value / примитив |
| `char` | `char` | 2 байта (16 бит) | value / примитив |
| `bool` | `boolean` | обычно 1 байт в C# / зависит от JVM | value / примитив |
| `decimal` | нет прямого аналога | 16 байт (128 бит) | value |
| `string` | `String` | ссылка + данные в куче | reference |
| `struct` | нет прямого аналога | зависит от полей | value |

### Беззнаковые типы и приставки в C#

В Java беззнаковых целых почти нет. В C# есть: `uint`, `ulong`, `ushort`, `sbyte`, `nint`, `nuint`.

| Приставка | Пример | Смысл |
|-----------|--------|--------|
| `s` | `sbyte` | знаковый байт (−128…127); обычный `byte` — беззнаковый |
| `u` | `uint`, `ulong`, `ushort` | только неотрицательные |
| `n` | `nint` | размер как у указателя (32/64 бита платформы) |
| `nu` | `nuint` | то же + беззнаковый |

### Чем `int` в C# отличается от Java

В C# `int` — это `System.Int32`: значимый тип со своими методами (`ToString`, `Parse`, `TryParse` и т.д.).  
В Java `int` — примитив; методы есть у обёртки `Integer`.

## 4. Лексемы

Лексема — минимальная неделимая единица языка.

| Вид | Что это | Примеры в C# |
|-----|---------|--------------|
| Идентификаторы | имена | `player`, `ToBinary` |
| Ключевые слова | зарезервированы языком | `class`, `interface`, `if` |
| Литералы | готовые значения | `42`, `"hello"`, `1.0f` |
| Операторы | действия | `+`, `-`, `&&`, `~` |
| Разделители | пунктуация | `;`, `{`, `}`, `,` |

### Контекстные ключевые слова

Обычные ключевые слова нельзя использовать как имена.  
Контекстные — ключевые **только в определённом месте**, в другом контексте могут быть идентификаторами.

| Слово | Смысл |
|-------|--------|
| `var` | тип выводит компилятор |
| `record` | особый вид типа (не «просто запись переменной») |
| `value` | входящее значение в `set` у свойства |

## 5. Вопросы на собеседовании

### Boxing и unboxing

- **Значимые типы** (`int`, `struct`): хранят само значение; копии независимы.
- **Ссылочные типы** (`class`, `string`): переменная хранит ссылку на объект в куче; две ссылки могут указывать на один объект.

**Boxing** — упаковка значимого в ссылочный (`object o = 5`).  
**Unboxing** — обратно (`int x = (int)o`).

### Где лежит `struct`, а где `class`

Упрощённо для экзамена:

- локальный `struct` в методе — обычно **стек** (живёт от `{` до `}`);
- `class` — **куча**;
- если `struct` — поле класса, он лежит **вместе с объектом в куче**.
